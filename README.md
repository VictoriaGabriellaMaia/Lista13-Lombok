# Lista13-Lombok

## Lombok

### Exercício 1 - Classes Pessoa, PessoaFisica e PessoaJuridica

Crie um pacote chamado `pessoa` com as classes `Pessoa`, `PessoaFisica` e `PessoaJuridica`.

**Requisitos:**

- As classes `PessoaFisica` e `PessoaJuridica` devem herdar da classe `Pessoa`.
- Todos os atributos das classes devem ser privados.
- Utilize as anotações da biblioteca Lombok para gerar os construtores e os métodos `get()` e `set()`.
- Na raiz do projeto, crie a classe `Principal`, responsável pela execução do programa.
- Na classe `Principal`, declare um vetor do tipo `Pessoa`.
- Permita que o usuário insira pessoas físicas ou jurídicas no vetor.
- Percorra o vetor e exiba os dados de cada pessoa utilizando o método `toString()` gerado pela biblioteca Lombok.

**Objetivo:** praticar herança, polimorfismo, encapsulamento e o uso da biblioteca Lombok em Java.
